
# Общий проект Г (Парковка)

В этой проектной работе вам предстоит реализовать приложение-сервис, которое отвечает за работу парковки и обрабатывает различные события.

## Что нужно сделать

Вам потребуется разработать приложение-сервис, который обрабатывает сигналы о прибывших или отбывших с парковки машинах.
После получения соответствующего сигнала должно меняться состояние парковочного места, которое может быть занято машиной или быть свободным. Кроме того, сервис делит парковочные места на разные категории - обычное, премиум и для электроавтомобилей. Все эти особенности необходимо учитывать при разработке сервиса.

На вход сервису подается список случайно сгенерированных клиентов с автомобилями и которые могут отправлять сигналы о парковке или об отъезде с нее. Таким образом, каждый запуск программы будет уникальным.

Кроме того, сервис будет работать до тех пор, пока есть хоть один клиент. Поэтому программа не должна прерываться, даже если возникла внештатная ситуация.

## Функциональные требования

Наш сервис управления парковкой должен выполнять обработку следующих задач:
- Прибытие клиента для парковки;
- Отбытие клиента с парковки;
- Постановка клиента на парковку и определение подходящего места. Каждое парковочное место имеет свой тип - обычное, премиум и для электроавтомобилей. Машины клиентов также имеют соответствующий тип. Обычное авто и электромобиль может припарковаться только на соответствующие этим типам парковочные места. Премиум автомобиль может припарковаться на премиум или обычное место.
- Освобождение места клиентом;

Помните, что ваш сервис будет вызываться извне, из основного цикла по сгенерированными данным. Вы должны учесть этот факт, и даже если произошла ошибка или поступило неверное сообщение, ответ сервиса всегда должен быть корректным. Не должно быть «подвисших в воздухе» вариантов, в которых программа не знает, что делать. То есть все условия и варианты должны быть учтены. Помните, что ваш сервис является чёрным ящиком для главной программы: если что-то пойдёт не по плану, данные могут быть утеряны или их целостность модели (то есть правильные связи объектов друг с другом) будет нарушена.

Для начала попробуйте реализовать недостающие методы `ParkingLot`, а далее уже перейти к обработчику.

## Нефункциональные требования

- Программа должна оставаться сервисом — то есть ей не должен требоваться никакой консольный ввод. Иначе программа будет зависать в ожидании.
- Программа не должна прерываться — то есть вызовы методов не должны приводить к ошибкам в программе.
